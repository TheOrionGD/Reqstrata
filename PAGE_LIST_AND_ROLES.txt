1. ARCHITECTURAL OVERVIEW OF NAVIGATION & ACCESS CONTROL
================================================================================

Access control in Reqstrata operates on three synchronized layers:

1. Centralized Routing (AppRoutes.kt):
   - Location: app/src/main/java/com/theoriongd/reqstrata/ui/navigation/AppRoutes.kt
   - Defines route contracts, deep link URL parameters, and role-to-dashboard resolution (getRoleDashboardRoute(role)).

2. Dynamic Graph & Bottom Navigation (DynamicNavGraphBuilder.kt):
   - Location: app/src/main/java/com/theoriongd/reqstrata/ui/navigation/DynamicNavGraphBuilder.kt
   - Dynamically assembles the Jetpack Compose NavHost graph at runtime based on the user's active role.
   - Tailors bottom navigation bar tabs so that only destinations authorized for that role appear.

3. RBAC & Data Governance (ProjectAccessPolicy.kt & RouteAuthorization.kt):
   - Location: app/src/main/java/com/theoriongd/reqstrata/domain/model/ProjectAccessPolicy.kt
   - Location: app/src/main/java/com/theoriongd/reqstrata/ui/navigation/RouteAuthorization.kt
   - Verifies user permissions against the MongoDB Atlas user collection (with fallback to local Room state).
   - If an unauthorized user navigates to a protected route, an "Access Restricted" screen appears with a direct link back to their role dashboard.
